# Nhạc và âm thanh tự chọn cho mini game

Chép file **mp3** đè lên đúng tên file trong thư mục này là game tự dùng, không cần sửa code.
File nào còn rỗng (0 KB) hoặc bị lỗi thì game dùng âm thanh có sẵn như cũ.

## Nhạc nền (tự lặp lại)

| File | Phát ở đâu | Gợi ý |
|---|---|---|
| `quiz-music.mp3` | Quiz Miệt Vườn: sảnh chờ và lúc khách trả lời | Không lời, vui nhộn, 2–3 phút |
| `lottery-music.mp3` | Lô Tô Miệt Vườn: nhạc nền màn hình TV | Không khí Tết, lễ hội |
| `tree-music.mp3` | Rung Cây Miệt Vườn: lúc cả phòng đang lắc | Vui tươi, không khí Tết |

## Hiệu ứng âm thanh

| File | Phát lúc nào | Gợi ý từ khóa tìm |
|---|---|---|
| `join.mp3` | Có khách vào phòng | `pop`, `bubble`, `ding` |
| `start.mp3` | Bắt đầu game / phát vé | `whoosh`, `swoosh` |
| `answer.mp3` | Khách bấm chọn đáp án (trên điện thoại) | `click`, `tap` |
| `tick.mp3` | Đồng hồ đếm giây cuối, đếm 3-2-1 | `clock tick`, `beep` |
| `time-up.mp3` | Hết giờ trả lời | `time up`, `buzzer` |
| `correct.mp3` | Trả lời đúng, vé còn giữ được | `correct`, `chime`, `bell` |
| `wrong.mp3` | Trả lời sai, vé bị trượt | `wrong`, `game show buzzer` |
| `fanfare.mp3` | Công bố top 3, người trúng giải, đội thắng | `fanfare`, `applause`, `tada` |
| `drum-roll.mp3` | Trống trước khi công bố bục vinh quang / lúc quay số | `drum roll` |
| `gong.mp3` | Ra số trúng (Lô Tô), bắt đầu và kết thúc vòng (Rung Cây Miệt Vườn) | `gong` |
| `firecrackers.mp3` | Có người trúng giải, đội thắng ván | `firecrackers`, `fireworks` |

## Lưu ý

- Hiệu ứng nên ngắn: dưới 3 giây (riêng `firecrackers.mp3` khoảng 5–8 giây). Mỗi file nên nhỏ hơn 1 MB, nhạc nền dưới 4 MB.
- Tải từ YouTube Audio Library (studio.youtube.com → Thư viện âm thanh) hoặc Pixabay. Bài nào cần ghi tên tác giả thì ghi vào `../CREDITS.md`.
- Muốn quay về âm thanh cũ: xóa file đó, hoặc thay bằng file rỗng.
- Thay file xong, bấm Ctrl+F5 trên TV để trình duyệt tải lại file mới.
